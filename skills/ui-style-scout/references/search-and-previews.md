# 检索与预览规则

## 组织搜索

先用“组件用途 + 关键状态或变体 + 平台/框架”定位，再加用户的视觉偏好。中文用于理解和本地生态，英文同义词用于扩大样例覆盖。

例子按需变换，不固定照抄：

- `searchable multi select grouped options Vue demo`
- `outlined search field clear button compact UI`
- `date range picker preset ranges dark theme demo`
- `settings sidebar organization switcher React example`
- `chat composer attachments model selector component`
- `下拉选择器 多选 搜索 分组 Vue 示例`

用 `site:来源域名 组件名 变体` 缩小范围。需要精确找图时，先从截图提取结构与词语；图片搜索可用于发现，再追溯到具体作者页面或官方示例。不要把搜索引擎缩略图当成可复用组件的证明。

默认在少量相关来源中发现比最终数量略多的候选，再淘汰重复或不匹配者。达到 3～5 个可靠且有差异的候选即可交付；用户未要求穷尽时无需继续扫站。检索深度随复杂度调整，不以固定搜索次数代替判断。

## 每个候选保留的依据

内部整理即可，无需输出冗长调查报告：

- 实际来源站点、组件名、变体名或示例编号。
- 组件具体页或独立 Demo 的链接；能定位的锚点可一并给出。
- 预览来自哪里，看到的是哪些状态，哪些尚未观察。
- 文档或代码表明的框架、依赖和接入方式；无法确认就保留未知。
- 只有在影响选择时才查费用、许可证、特定高级功能等信息。

以站点自身文档、作者实例或官方仓库为技术事实依据。灵感站的图可以支撑外观判断，不能单独支撑“代码可直接使用”“已经实现无障碍”等技术结论。

## 预览获取顺序

1. **已有可信媒体**：使用工具已返回并允许展示的具体组件原图、动图或视频预览。
2. **真实网页截图**：在浏览器或计算机使用能力可用时，遵循该工具及相关 skill 的规则，以只读方式查看外部 Demo 并截取候选区域。截图保留足够上下文，准确对应链接和变体。
3. **原站查看**：没有可展示媒体或截图能力时，给出具体 Demo 链接、已确认的状态和简短外观说明，明确预览缺失。至少尽力为主要推荐取得真实可见依据。

优先直接在会话展示 3～5 个候选；不要为了排版默认创建网站、安装截图工具、运行开发服务器或生成复杂对比应用。若当前工具能低成本输出真实截图对比，可以采用，但逐图保留来源对应关系。

获取选择器展开态、聚焦态等必要状态可以在外部 Demo 中进行最少的只读交互。不提交表单、不触发支付、不发消息、不改账号状态；这类任务通常用不到登录。已有可用访问权限时按其边界使用，遇到付费墙改用公开替代来源。

不要要求用户提供截图来弥补所有网站访问问题。先尝试公开 Demo、官方文档、作者仓库和其他来源；确实影响准确识别输入时，再请求缺失的参考图。

## 媒体真实性与展示

- 标明真实截图所对应的来源、变体与状态；静态图不能证明悬停、展开、流式输出等行为。
- 不使用生成图或自绘图冒充搜索结果。用户另行要求概念变体时可以单独制作，并标为概念稿，不计入已确认的网站实例。
- 优先使用连接器原生显示的媒体、工具已返回的本地文件或允许嵌入的原始远程媒体；不能展示时给可访问的原始链接。
- 不下载远程媒体来绕过应用展示限制。按当前环境规则处理本地输出位置、绝对路径和图片引用。
- 不把登录页、首页封面、来源站 Logo 或整页不相关区域作为组件预览。

## 访问与证据不足

| 情况 | 处理方式 |
| --- | --- |
| 文本能读、视觉不能确认 | 记录组件与文档依据；不靠文字推断外观，尝试浏览器或其他来源 |
| 客户端渲染、403、超时或工具格式不支持 | 换具体 Demo、作者仓库或允许的浏览器路径；仍失败就换来源 |
| 登录或付费限制 | 说明可见范围，优先公开候选；不购买或要求用户登录后才能继续整个任务 |
| 找不到截图原款 | 提供相似款，说明相似和不同；不猜测原站身份 |
| 只找到 1～2 个可信款式 | 交付实际数量并说明缺口；不把未经查看的线索混成已确认候选 |
| 完全不能联网 | 说明未完成实时搜索；如有帮助，给标为“待验证”的来源线索，不虚构预览与结果 |

来源选择是实时的；不要把某次访问失败写成永久不可用，也不要在之后沿用未核实的价格或兼容性。
