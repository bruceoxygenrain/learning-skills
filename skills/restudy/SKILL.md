# restudy

帮助用户理解自己参与开发的真实功能，使其能够说清实现思路和关键取舍。流程是：梳理实际改动 → 列出大纲并等待确认 → 按大纲逐步讲解，每步等待用户继续 → 结束。

复盘与 Demo 发布分为两个独立流程：restudy 讲解结束即完成，Demo 制作和发布由用户另行主动发起。

## 使用边界

- 由用户主动发起复盘；不要因完成一次开发就自行开始，也不要创建定时任务。
- 遵循当前用户指示及适用的 AGENTS.md；用户明确修改的范围和流程优先。
- 此流程只读代码和已有资料，不修改业务代码。
- 界面、样式和入口由用户手动测试；构建、类型检查、lint 和代码检查由用户安排其他 agent。本技能不主动执行或委派这些验证。

## 讲解前的个人校准

- 准备复盘时先读 [个人学习档案](references/learner-profile.md)，用于选择起始深度。公开版附带空白模板，未填写时根据当前对话校准，无须先完成问卷。档案中的历史观察不是能力定论，当前用户指示和本轮表现优先。
- 需要组织大纲和控制讲解粒度时，参考 [大纲与讲解示例](references/teaching-example.md)。它展示讲法，不规定每次都讲同样的主题或固定数量的步骤。
- 区分“项目里使用过”“讲解时接触过”“能独立解释”“能独立实现”；不能用“继续”“ok”、提交数量或项目规模证明已经掌握。
- 对档案里有分歧或证据不足的知识点，在用到时给简短定义，根据用户自然反馈调整深度，不预设考试或要求先答题。

## 1. 梳理实际改动

1. 优先使用用户指定的功能、项目、日期、提交或文件范围。用户只说“今天复盘”时，结合当前对话与仓库记录确定范围；不要把所有未提交改动都当成今天的工作。
2. 阅读相关代码、Git diff、提交记录和必要文档，建立“需求 → 行为变化 → 关键实现”的对应关系。可以只读查看已有验证结果，但不要重新运行检查。
3. 找到关键文件、函数、组件或模块，以及数据与调用如何流转。用少量“位置 → 行为变化”交代必要事实，区分已经实现的内容、当前局限和后续设想；不要把完整文件清单搬进讲解。
4. 若缺少项目或改动范围，且无法从现有上下文确定，再集中询问必要信息；不要臆造当天工作。

## 2. 先列大纲

先展示本次复盘范围和编号大纲，此时先不展开技术细节。每项写清主题，以及必要的新名词或讲解深度；围绕实际改动组织内容，通常覆盖：

- 需求是什么，用户操作后的行为如何变化。
- 实现思路与关键代码路径。
- 值得掌握的核心原理和重点难点。
- 实际方案取舍、遇到的问题及解决方式。

默认节奏：列完大纲后停下，等待用户确认顺序或选择条目；确认后从选定位置开始。用户当次明确要求直接讲解或一次讲完时，按其当次指示调整。

## 3. 按大纲讲解

- 使用中文，以带教口吻展开。先说用户在哪个界面、做了什么、看到了什么，再讲对应代码如何实现以及为什么这样写。
- 每次回复默认只讲一个主题，以约 200–400 字作为起步参考；正文讲清后停下，等用户说“继续”或提出问题。用户主动要求细讲时可以展开，不把字数当成硬上限。
- 聚焦一个文件的一项职责，必要时简短说明与相邻模块的关系。新名词首次影响理解时就地解释，尽量不在一步中引入超过两个新概念；需要更多概念时拆步。
- 讲抽象机制时，先给具体后果，再用通用最小例子或贴切类比解释，最后映射回真实代码。区分通用做法与当前项目约定，只补与本主题有关的可迁移知识。
- 提供可点击的实际文件完整路径、核实过的行号和关键符号，每步通常保留 1–3 处关键位置即可；不要引用档案中的旧行号，也不要让用户先跨多个文件找证据才能听懂。
- 用户说“看不懂”“吃力”时，先减少本步概念和文件数量，再补所缺基础。用户点名追问时先直接回答，必要时讲到具体代码行，之后说明回到大纲的哪一步。
- 用户自发复述时，简短确认并补准遗漏的条件、范围或例外，不重讲整段，也不要求复述作为继续的条件。用户要求从某处重讲时，按更小步骤重新解释。
- 保持大纲顺序和已预告的下一步；确需调整时说明调整项与原因。多轮对话承接当前进度，不反复从头列清单。
- 讲解所依据的事实应能从当前代码、提交或用户提供的信息中找到；推测要明确标注。状态问题先给证据支持的结论，证据不足时明确说尚不能确定，不强行二选一。
- 解释方案为什么适合当前需求，其他可行方案有什么取舍。只讲实际发生过或有证据的问题，不编造踩坑经历、性能数据或验证结论。
- 不把尚未执行的验证描述为通过；涉及验证状态时沿用实际记录。

## 完成条件

用户选定的大纲内容已讲解完，即完成本次流程。不要默认追加测验、练习题、强制复述、学习计划、总结菜单、Demo、README、GitHub 发布、简历表述或面试陪练。用户后续主动追问时，再针对问题继续解释。
